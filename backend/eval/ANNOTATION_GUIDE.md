# 标注说明

打开 `annotate.csv`，只填 `label` 和 `notes` 两列，其他列不要改。

每一行是模型给出的一条证据。看三列：

- `claim`：模型写的论断
- `quote`：模型引用的原文（一句话）
- `field`：这条论断属于论文的哪一部分（研究问题 / 方法 / 实验 / 结论 / 局限）

问一个问题：**只看这句原文，能不能得出这个论断？**

| label | 含义 | 例子 |
|---|---|---|
| **Y** | 能。原文直接说了论断的内容，或论断是原文的合理转述 | 论断"模型用了 8 个注意力头"；原文 "we employ h = 8 parallel attention layers" |
| **P** | 部分能。原文只撑住一半；或论断比原文说得更强 | 论断"翻译和解析任务上都超过 SOTA"；原文只提了翻译 |
| **N** | 不能。原文和论断不是一回事，只是沾边；或原文是背景不是本文结论；或论断的关键数字/结论原文里没有 | 论断"误差降到阈值以下"；原文 "previous work reported error rates above threshold" |

拿不准按 P，在 `notes` 里写一句原因。

**claim 里有多个 `[ID]` 时**：模型把论断拆给了多条引用，只看这条 quote 撑不撑得住它对应的那部分。撑住就 Y，不要因为 claim 里还有别的内容判 P。只有一个 `[ID]` 时，整句 claim 都由这一条 quote 负责。

三条注意：

1. **不要翻全文**。只看这句原文够不够。去翻论文就是在替模型补证据。
2. **不评论断本身对不对**，只评"这句原文撑不撑得住它"。
3. 论断里写着"原文未明确提及"的行，一律 N——模型一边说没提到一边又引了原文，自相矛盾。

标准一致比每条都对更重要：所有人用同一套尺子，数字才能放一起。
